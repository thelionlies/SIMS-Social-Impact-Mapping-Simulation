# Social Impact Mapping Simulation

A **Java-based two-party election simulation** implementing principles of **Social Impact Theory** (Nowak, Szamrej, & Latané, 1990).  

This project was developed for the Programming with Databases class in MDSc at Ateneo de Manila University. It showcases a simple GUI, basic Java programming concepts, and simulation of social influence dynamics in a two-party election scenario.

---

## Features

- Basic Java GUI for visualizing the simulation  
- Simulates voter opinion dynamics under social influence  
- Designed for educational purposes and demonstration of Java programming skills  

---
